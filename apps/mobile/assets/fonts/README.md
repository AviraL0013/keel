# Manrope font assets

The app bundles the existing theme's regular, semibold and bold variants so typography does not require a font-service request. Files come from Google's font service and match the SHA-256 values pinned by `google_fonts` 6.3.3:

- `Manrope-Regular.ttf`: `1ddeeeff9fe3d294f709f2239557278930f56dab89db1fe535dc5c35cd67e0ee`
- `Manrope-SemiBold.ttf`: `8791ca409cf36b8b2842e40b6b1cd5b42cca064b4fdf24e30f5611536793429d`
- `Manrope-Bold.ttf`: `e7793683898d8a0e4c97ec50116fc021d053f2f72113982076a50a9048f101b5`

Source URLs use `https://fonts.gstatic.com/s/a/<SHA-256>.ttf`. The accompanying license is from [Google Fonts' Manrope directory](https://github.com/google/fonts/tree/main/ofl/manrope). Manrope is licensed under the SIL Open Font License 1.1; see `OFL-Manrope.txt`.
