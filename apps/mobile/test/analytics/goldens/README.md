# Analytics screenshot baselines

These tests use exact pixel comparison. Flutter's native font and icon rendering differs between Windows and Linux even when the SDK and font files match. The files in this directory were generated on Windows; `linux/` contains the Ubuntu CI baselines for Flutter 3.47.5 / Dart 3.13.4.

The Linux images were captured by CI run [37677142314](https://github.com/AviraL0013/keel/actions/runs/37677142314) at commit `dbbeec9ff7b211db626236e58831f9ef62e8e544`. Review compared expected, actual and isolated difference images before accepting them. Differences involved glyph and icon edges, plus the liquidation timestamp in the desktop market screenshot (Windows used IST; CI used UTC). Card borders, colors and chart geometry were unchanged. Fixture event timestamps now use a fixed local wall clock on every host. A regression reproduced the timezone difference before this change, and the Windows desktop market baseline was reviewed again after its intended clock update. Production still displays the user's local timezone. The 1280 dp protocol screenshot has a three-pixel tolerance for bottom-edge pixels that differ from its reviewed baseline on Windows and in three consecutive Linux CI runs. Every other screenshot remains exact. No baseline updates or screenshot tests are skipped.

The analytics UI polish refreshed Windows and Ubuntu baselines with Flutter 3.47.5. Ubuntu rendering used an isolated checkout of the same Flutter revision (`6a19cca564`) and a copy of the mobile test tree. Its unchanged search screenshot matched the previous Ubuntu baseline byte for byte before the updated images were copied back. Reviewed changes show chart axes and dates, a volume sparkline, proportional skew, source and coverage text, aligned desktop market columns, and two-column phone wallet metrics. The existing protocol-1280-only three-pixel tolerance remains unchanged; all other screenshots still compare exactly.

To update a baseline intentionally, use the pinned Flutter SDK on the corresponding OS, run `flutter test test/analytics/analytics_screen_test.dart --update-goldens`, inspect every changed image, and then rerun the same test without `--update-goldens`. A new host OS requires its own reviewed baseline; the existing fallback has only been verified on Windows. Screenshot fixtures freeze event wall-clock labels independently of the host timezone; production timestamp parsing has separate canonical-fixture tests.
