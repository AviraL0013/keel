# Analytics screenshot baselines

These tests use exact pixel comparison. Flutter's native font and icon rendering differs between Windows and Linux even when the SDK and font files match. The files in this directory were generated on Windows; `linux/` contains the Ubuntu CI baselines for Flutter 3.47.5 / Dart 3.13.4.

The Linux images were captured by CI run [37677142314](https://github.com/AviraL0013/keel/actions/runs/37677142314) at commit `dbbeec9ff7b211db626236e58831f9ef62e8e544`. Review compared expected, actual and isolated difference images before accepting them. Differences involved glyph and icon edges, plus the liquidation timestamp in the desktop market screenshot (Windows used IST; CI used UTC). Card borders, colors and chart geometry were unchanged. Fixture event timestamps now use a fixed local wall clock on every host. A regression reproduced the timezone difference before this change, and the Windows desktop market baseline was reviewed again after its intended clock update. Production still displays the user's local timezone. There are no tolerance overrides, automatic baseline updates, or skipped screenshot tests.

To update a baseline intentionally, use the pinned Flutter SDK on the corresponding OS, run `flutter test test/analytics/analytics_screen_test.dart --update-goldens`, inspect every changed image, and then rerun the same test without `--update-goldens`. A new host OS requires its own reviewed baseline; the existing fallback has only been verified on Windows. Screenshot fixtures freeze event wall-clock labels independently of the host timezone; production timestamp parsing has separate canonical-fixture tests.
