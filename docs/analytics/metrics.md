# Analytics metric definitions

Network: Monad mainnet (chain 143), Perpl Exchange `0x34B6552d57a35a1D042CcAe1951BD1C370112a6F`. Collateral is AUSD with six decimals. Monetary JSON values are decimal strings with six places. Integer base units stay integers until formatted. `asOf` and `block` identify latest finalized evidence; provisional head events never enter totals.

## Protocol

| Metric                   | Definition                                                                                                                                                                                                                                                                                                                                   | Evidence                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Trading volume           | One notional per matched maker fill, `pricePNS × lotLNS / 10^(priceDecimals + sizeDecimals)`, rounded to nearest AUSD micro at fill boundary. Includes opens, reductions and closes; excludes cancellations, funding and liquidation transfers. A market's public candle `v` is independent comparison, not silently mixed into this series. | `MakerOrderFilled` / `MakerOrderFilledV2`; market precision from public context. |
| Open interest            | Sum of absolute notional of open positions valued at current mark. Perpl public market `state.oi` gives base size; convert using market size decimals and current `state.mrk`. Long and short OI each represent one side; aggregate OI counts one side only, never long plus short.                                                          | Public `GET /v1/pub/context`, then indexed position sides for skew.              |
| TVL                      | Sum of market `state.tvl` collateral base units, divided by 10⁶. This is venue-reported market collateral, not wallet token balances or all deposits ever made.                                                                                                                                                                              | Public context.                                                                  |
| Fees                     | Sum of gross trading fee debits for unique fill sides, minus rebates where reported. Gross includes any builder fee. Fee values from maker and taker fill events must not be combined with position `protFeeCNS` for same settlement.                                                                                                        | Exchange maker/taker fill events.                                                |
| Revenue                  | Sum of protocol fee credited on position opens, increases and inversions. Insurance and builder fees are excluded. Do not label gross fees as revenue.                                                                                                                                                                                       | Position `protFeeCNS`; otherwise null.                                           |
| Active users             | Distinct account owners with at least one settled matched fill in window. An account trading many markets counts once. Account-to-wallet mapping comes from `AccountCreated`.                                                                                                                                                                | Exchange fills and account mapping.                                              |
| Liquidations             | Count of `PositionLiquidated` events. Notional is liquidated lot times liquidation price; partial liquidations still count once per event.                                                                                                                                                                                                   | Exchange event.                                                                  |
| Deposits and withdrawals | Gross external collateral movement into/out of Exchange accounts from `CollateralDeposit` and `CollateralWithdrawal`. Account creation deposit counts only if a deposit event occurs. Internal protocol transfers, realized PnL and funding are excluded.                                                                                    | Exchange events.                                                                 |
| Net capital flow         | Gross deposits minus gross withdrawals in same UTC interval. Negative value means net outflow.                                                                                                                                                                                                                                               | Derived from collateral events.                                                  |
| Funding rate             | Signed actual rate for completed funding interval; no annualization. Latest estimated public funding event may be shown with source `perpl_api`, but completed chain event is canonical for history.                                                                                                                                         | `FundingEventCompleted` / public funding endpoint.                               |

Windows are half-open `[from,to)` in UTC. `24h`, `7d` and `30d` end at `asOf`; comparison period has same duration immediately before. `all` begins at verified Exchange deployment block and has no prior comparison. Snapshot OI and TVL compare boundary values; additive metrics sum events in each period. Delta percent is `(current - previous) / abs(previous) × 100`; null if previous is zero or either side unavailable. Hourly and daily buckets use UTC boundaries.

While archive backfill is incomplete, `all` starts at the earliest indexed block. The API labels it `Since YYYY-MM-DD` and sets `coverage.completeHistory` to false. Once the configured deployment block is fully replayed and the worker is caught up, the label becomes `All time`.

## Wallet

An indexed wallet can own multiple Exchange account IDs. Aggregate margin across its accounts; do not mix wallet AUSD balance with Exchange margin. Available margin is account balance minus locked balance. Equity is balance plus current unrealized PnL when marks and funding are verified; otherwise null.

Open positions use the latest finalized position state per account and market. Size uses market size precision, entry and mark prices use market price precision, leverage uses hundredths. Unrealized PnL includes price movement and funding only when both formulas and inputs are verified. Liquidation price stays null until the venue's maintenance, funding and fee formula is independently checked. Unknown values stay null rather than guessed.

A trade is a settled position-changing fill. For a reduction, close or liquidation, realized PnL is `deltaPnlCNS + fundingCNS` from its position event, in AUSD. Opening fills have null realized PnL. Position event matching uses transaction and account/market; ambiguous multi-fill transactions remain unresolved, not double counted.

Performance uses closed position episodes, not every fill. Win rate is profitable episodes divided by episodes with known realized PnL. Breakeven episodes count in denominator. Profit factor is gross positive realized PnL divided by absolute gross negative realized PnL; null when no losses. Max drawdown is greatest peak-to-trough percent on the realized equity curve, null without a known starting equity. Streaks count consecutive winning or losing closed episodes; breakeven resets both. Hold time is close minus open time, averaged across closed episodes. Best/worst markets rank by summed realized PnL, ties by market ID. A partially indexed history makes performance stale and incomplete; such metrics are null until backfill reaches deployment block.

Raw history coverage does not prove complete settlement reconstruction. An unresolved maker or position account owner keeps wallet performance unavailable, because that account could belong to the requested wallet. `PositionDeleveraged`, `PositionDeleveragedV2`, `PositionUnwound` and `PositionUnwoundV2` are recorded but do not yet have verified performance formulas. Their owner's episode metrics and the affected market's indexed skew remain null. Other verified wallets and markets remain usable. Contract perpetual IDs are resolved through public context to API market IDs; missing or ambiguous mappings fail closed.

Performance and skew are bounded to the observed checkpoint block. Their cache identity includes coverage boundaries, checkpoint revision and block hash. The server rechecks that identity after reading settlements; a concurrent rewind returns `ANALYTICS_HISTORY_CHANGED` (503, `Cache-Control: no-store`) rather than mixing old coverage with new events. Replay at the same height and hash still invalidates the previous cache revision.

## Provenance and limits

Perpl [vendored API docs](../vendor/perpl-api-docs/rest-endpoints.md) expose public context, candles and funding. Account history, fills and positions require signed API-key access, so public wallet coverage depends on Exchange logs. The event ABI subset is captured from [Perpl's official SDK](https://github.com/PerplFoundation/dex-sdk/blob/main/crates/sdk/abi/dex/Exchange.json) with source hash in `exchange-events.ts`. On-chain mapping and calculations must pass recorded-log tests before publishing non-null wallet metrics.
